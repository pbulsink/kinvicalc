# Format a sample type code as a human-readable label.

Format a sample type code as a human-readable label.

Format a sample type code as a human-readable label.

## Usage

``` r
format_sample_type_label_app(sample_type)

format_sample_type_label_app(sample_type)
```

## Arguments

- sample_type:

  A sample type code.

## Value

A character scalar title-case label, e.g. `"base_oil"` becomes
`"Base Oil"`.

## Examples

``` r
format_sample_type_label_app("base_oil")
#> [1] "Base Oil"
```
